🧾 Configuração fiscal da empresa

Cadastre apenas dados públicos/administrativos. Não coloque senha de certificado, token de API nem CSC secreto neste HTML. Esses segredos deverão ficar no backend seguro.

🏢 Dados cadastrais já registrados

🔒 Ativação de Produção protegida

Trocar o ambiente para Produção não liga emissão por conta própria. O sistema primeiro valida cadastro, backend, certificado, credenciamento, CSC quando aplicável, leiaute e produtos. Segredos continuam fora do HTML.

🔐 Certificado, senha, CSC secreto e token fiscal: somente no backend seguro.
IBS/CBS, CST, classificação tributária, CFOP e demais regras de cada produto serão armazenados no banco, mas os valores corretos deverão ser definidos com a contabilidade/solução fiscal atualizada antes da emissão real.
